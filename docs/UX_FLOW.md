# AI Stock Alarm - UX 핵심 시나리오 (UX Flow)

## 1. 온보딩 (Onboarding)
- **진입점**: 앱 최초 실행 시 또는 로그아웃 상태일 때
- **목표**: 사용자 개인화 설정 (관심 종목/섹터, 투자 성향 설정)
- **흐름**:
  1. `LoginPageV2`: 서비스 소개 및 로그인 유도.
  2. `OnboardingPageV2`: 
     - 사용자의 관심 종목 및 섹터 선택 (최대 3개).
     - 기본 투자 리스크 성향 선택 (안정형, 중립형, 공격형).
  3. 설정 완료 시 `HomePageV2`로 이동.

## 2. 데일리 추천 확인 (Home)
- **진입점**: 로그인 완료 후 기본 화면
- **목표**: 오늘의 핵심 매매 추천 확인 및 의사 결정
- **흐름**:
  1. `HomePageV2` 로드 시 사용자의 투자 성향과 관심 종목에 부합하는 추천 카드 3개 노출.
  2. 상단 리스크 성향 탭(Confidence Score)을 눌러 다른 성향의 추천 확인 가능.
  3. 각 추천 카드에서 다음 액션 수행:
     - **가격 복사**: 진입가/목표가를 클립보드에 복사.
     - **매매**: 증권사 앱(브로커) 딥링크 이동 시뮬레이션.
     - **상세**: `RecommendationDetailPageV2`로 이동하여 상세 근거 확인.

## 3. 추천 상세 확인 및 행동 (Recommendation Detail)
- **진입점**: 추천 카드에서 '상세' 버튼 클릭
- **목표**: 특정 추천에 대한 AI의 판단 근거 및 성과 확률 확인
- **흐름**:
  1. `RecommendationDetailPageV2`에서 뉴스/거래량/커뮤니티/패턴 신호 요약 확인.
  2. 해당 종목의 과거 추천 성공률, 평균 수익률 등 퍼포먼스 통계 확인 (신뢰성 확보).
  3. 하단 액션 버튼을 통해 **알림 설정**, **가격 복사**, **브로커 앱으로 이동**.

## 4. 과거 이력 조회 (Archive)
- **진입점**: 하단/상단 네비게이션바의 '이력' 탭 클릭
- **목표**: 과거 AI 추천의 성공/실패 기록을 투명하게 확인
- **흐름**:
  1. `ArchivePageV2`에서 전체 또는 특정 종목별 과거 추천 이력 필터링.
  2. 각 이력 항목에 대해 `성공`, `실패`, `평가 중` 상태 및 실현 수익률 확인.

## 5. 앱 환경 및 성향 설정 (Settings)
- **진입점**: 네비게이션바의 '설정' 탭 클릭
- **목표**: 푸시 알림, 관심 종목, 투자 성향 재조정
- **흐름**:
  1. `SettingsPageV2`에서 언제든 관심 종목(최대 3개) 변경 및 저장.
  2. 투자 성향(리스크 프로필)을 변경하면 홈 화면의 기본 탭에 즉시 반영.
  3. 푸시 알림(아침 브리핑) 켜기/끄기 설정.
  4. 테스트를 위한 상태 페이지(No Call, Loading, Empty, Error) 확인 기능 지원.

## 6. 예외 상태 경험 (State Pages)
- **진입점**: 데이터 로드 지연, 서버 에러, 추천 없음 등의 예외 상황
- **목표**: 사용자에게 명확한 현재 상태를 알리고 다음 행동(Fallback) 유도
- **흐름**:
  - `No Call`: 오늘은 확실한 추천이 없음을 투명하게 알리고 관심 종목 변경 유도.
  - `Empty`: 아직 이력이 없을 때 데이터 축적 중임을 알림.
  - `Error/Loading`: 직관적인 UI 뼈대(Skeleton)나 에러 복구 버튼 제공.
